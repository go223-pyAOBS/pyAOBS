# idata 帮助

数据转换与道头编辑工区。工具栏 **帮助**（或 `F1`）打开本页；窗口为非模态，可不关窗继续操作主界面。

```
[工具栏] 新建工区 | 打开工区 | 保存工区 | 帮助 | 退出 | 打开 SEGY/SU | 保存数据 | 另存为 | 导出 SU | 清空日志
[阶段]   1 转换 | 2 道头编辑 | 3 工区几何
```

---

## 1. 推荐工作流

1. **新建/打开工区**（目录含 `meta/idata_project.json`、`inputs/`、`outputs/`）
2. **1 转换**：分步或一键流水线产出 SEGY/SU
3. **打开 SEGY/SU**（或转换完成后自动加载）→ **2 道头编辑**
4. **3 工区几何**：核对炮/OBS 平面分布、`scalco`/`scalel`/`counit`、offset
5. **保存数据**（`Ctrl+S`）写回道头；**保存工区** 只存工程状态

---

## 2. 工区几何总览（必读）

几何相关问题几乎都来自三件事混在一起：

1. **槽位名**（道头字段 `sx/sy/gx/gy/…`）≠ **物理角色**（谁是炮、谁是 OBS）
2. **整型原值** 必须经 **`scalco` / `scalel`** 才变成物理量
3. **`counit`** 声明 XY 是米还是经纬度（弧秒/度）

idata 转换默认按 **SEG-Y 字面** 写入：**炮 → s\***，**OBS → g\***（`geom=segy`）。  
历史「对调装填」数据请用几何页 **旧对调**（`geom=obs`）解释/成图，或用道头工具真正交换 s\*/g\*。

---

## 3. 解释模式：`geom=segy` vs `geom=obs`

| 模式 | UI 选项 | 物理炮点 ← | 物理 OBS ← | 适用 |
|------|---------|------------|------------|------|
| **segy**（idata 默认） | 约定：炮←sx,sy，OBS←gx,gy | `sx,sy`（及 `selev`/`sdepth`/`swdep`） | `gx,gy`（及 `gelev`/`gwdep`） | 本工区 **转换产出**、标准 SEGY |
| **obs** | 旧对调：炮←gx,gy，OBS←sx,sy | `gx,gy`（及 `gelev`…） | `sx,sy`（及 `selev`…） | 历史对调数据、部分 RTM/旧流程 |

要点：

- 切换解释模式 **只改成图与角色映射**，**不改文件字节**。
- 若文件本身写反了，应在道头页 **交换 s\*/g\***（或任意字段交换）后 **保存数据**。
- 平面图图例会标明「炮点 ← … / OBS ← …」；计数为去重后的炮点数 / OBS 数。

## 4. 道头几何字段一览

字节偏移与 `processors/raw2sac/segy_trace_header.py` / `segy.h` 一致。

### 4.1 平面坐标与比例（`scalco`）

| 字段 | 类型 | 字节 | 含义 |
|------|------|------|------|
| **scalco** | i16 | 71–72 | 作用于 **sx, sy, gx, gy** 的比例 |
| **sx** | i32 | 73–76 | Source X 槽（字面=震源东向/经度） |
| **sy** | i32 | 77–80 | Source Y 槽 |
| **gx** | i32 | 81–84 | Group X 槽（字面=检波东向/经度） |
| **gy** | i32 | 85–88 | Group Y 槽 |
| **counit** | i16 | 89–90 | 上述 XY 的单位类型（见第 6 节） |

**物理 XY**（idata 显示 / offset 计算前）：

```text
scale > 0  →  物理量 = 整型 × scale
scale < 0  →  物理量 = 整型 ÷ |scale|     ← 负号表示「除」，不是乘负数
scale = 0 或 ±1  →  不缩放（整型即物理量）
```

例：`scalco = -100`，`sx = 51234567` → 东向米 = `51234567 / 100 = 512345.67 m`。  
本工区转换默认：`scalco = -1`（与 `+1`/`0` 一样不缩放），`counit = 1`（米）。

### 4.2 高程 / 深度与比例（`scalel`）

| 字段 | 类型 | 字节 | SEG-Y 字面含义 | 备注 |
|------|------|------|----------------|------|
| **scalel** | i16 | 69–70 | 作用于下列高程/深度字段的比例（规则同 scalco） | 与 scalco **独立** |
| **gelev** | i32 | 41–44 | 检波点（group）高程 | 海平面以上为正 |
| **selev** | i32 | 45–48 | 震源（source）高程 | 海平面以上为正；海底常为负 |
| **sdepth** | i32 | 49–52 | 震源深度 | **恒为正**（相对地表/海底约定以数据为准） |
| **gdel** | i32 | 53–56 | 检波点基准面高程 | 较少用 |
| **sdel** | i32 | 57–60 | 震源基准面高程 | 较少用 |
| **swdep** | i32 | 61–64 | 震源处水深 | |
| **gwdep** | i32 | 65–68 | 检波点处水深 | |

物理高程/深度 = `scale_segy_factor(整型, scalel)`。  
本工区转换默认：`scalel = -1`。

角色随 `geom` 变化（与 XY 同一套映射）：

| 物理量 | geom=segy（默认） | geom=obs（旧对调） |
|--------|-------------------|---------------------|
| 炮点高程/水深 | `selev` / `sdepth` / `swdep` | `gelev` / `gwdep` |
| OBS 高程/水深 | `gelev` / `gwdep` | `selev` / `sdepth` / `swdep` |

### 4.3 炮检距 `offset`

| 字段 | 类型 | 字节 | 含义 |
|------|------|------|------|
| **offset** | i32 | 37–40 | 炮检水平距（米）；**不受 scalco / scalel** |

- 可带符号（处理里有时用符号表示方位）；**检查时比较绝对值**。
- idata **重算 offset**：先对 XY 做 scalco，再  
  `hypot(sx−gx, sy−gy)`（槽位差；两模式水平距相同）。
- **offset 检查**：`|道头 offset|` vs 上述 xy 距离，容差默认 5 m。

## 5. `scalco` / `scalel` 速查与示例

| 取值 | 运算 | 例（整型 1234567） |
|------|------|-------------------|
| `+10` | ×10 | 12345670 |
| `-10` | ÷10 | 123456.7 |
| `-100` | ÷100 | 12345.67 |
| `-1000` | ÷1000 | 1234.567 |
| `0` / `±1` / `-1` | 不缩放 | 1234567 |

注意：

1. **不要**把 `scalco=-100` 理解成「乘 −100」。
2. 改坐标整型后，若小数位变了，应同步改 `scalco`；只改一边会整体缩错。
3. 高程用错 `scalco`、坐标用错 `scalel` 是常见误操作——二者管辖字段不同。
4. 几何页「运行检查」会统计可疑 `scalco`（如极端值）。

---

## 6. 坐标单位 `counit`（最易出错）

声明 **sx/sy/gx/gy**（经 scalco 后）的单位：

| counit | 含义 | 说明 |
|--------|------|------|
| **1** | 长度（米或英尺） | **投影坐标 / 本工区默认**；米/英尺见卷头 Measurement System |
| **2** | 弧秒（seconds of arc） | 经纬度用角秒；规范已不推荐 |
| **3** | 十进制度（decimal degrees） | 经纬度用度（推荐的角度写法） |
| **4** | 度分秒 DMS | 特殊打包（与 scalco 配合，见 SEG-Y） |
| **0** | 未填写 | 常见，但不等于合法单位 |

`counit` 为 2/3/4 时：X=经度、Y=纬度；东/北为正，西/南为负。

### 6.1 示例：东经 120.5°、北纬 30.25°

**counit = 2（弧秒）**，`scalco = 1`：

- `sx = 120.5 × 3600 = 433800`，`sy = 30.25 × 3600 = 108900`

**counit = 3（十进制度）**，`scalco = -10000`：

- `sx = 1205000` → 120.5°，`sy = 302500` → 30.25°

**量级对照**

| 写法 | 120.5° 附近整型量级 |
|------|---------------------|
| 弧秒 (2) | ~**43 万** |
| 十进制度 (3, scalco=-10000) | ~**1205000** |
| 米制投影 (1) | 常为 **10⁶～10⁷**（视投影） |

### 6.2 常见坑

1. counit 标成 2，实际却是「度×10ⁿ」→ 误标，按量级改正。
2. 米坐标却标 counit=2/3 → offset/成图距离无意义；应为 **1**。
3. 本工区转换默认：`counit=1`，`scalco=scalel=-1`。
4. 未统一单位就做 offset 检查 → 「全不一致」往往是单位问题，不是几何真错了。

## 7. 几何页与道头页怎么用这些字段

### 7.1 工区几何页

- 按当前 **解释模式** 把物理炮 / OBS 画在平面图上（已 scalco）。
- **offset 检查**：容差 spinbox；报告含一致/不一致、counit/scalco 分布。
- **运行检查**：缺坐标、可疑 scalco、offset 来源等摘要。
- 与道头表、道集预览 **点击联动高亮**；切换页签尽量 **保持缩放**。

### 7.2 道头编辑页

- 几何相关列置顶：`offset, scalel, scalco, sx, sy, gx, gy, gelev, selev, sdepth, swdep, gwdep, counit`。
- 状态栏/提示可显示 **scalco 后的槽位坐标** 与 **按 geom 解释的炮/OBS**。
- **重算 offset** / **offset 检查** / **交换 s\*/g\***：均非模态。

### 7.3 检查清单（打开数据后建议顺序）

1. 看 `counit`、`scalco`、`scalel` 众数是否合理  
2. 选对 **解释模式**（约定 vs 旧对调）  
3. 几何图：炮点数、OBS 数是否符合工区  
4. offset 检查（先小容差抽样）  
5. 需要时再批量改头并 **保存数据**

## 8. 道头编辑（其它）

- 表格编辑脏道头；**保存数据** 写回文件（不是「保存工区」）。
- **另存为**：
  - 同格式（SU→`.su` 或 SEGY→`.segy`/`.sgy`）：整文件拷贝 + 当前道头。
  - **跨格式会真正转换**：SEGY→`.su` 经解码写出 IEEE SU；SU→`.segy`/`.sgy` 写 3600 卷头 + IEEE（format=5）SEGY。  
    **不要**指望「只改后缀」；旧版若混选后缀而不转换会得到错误文件。
- **列填充 / 条件批量 / 任意字段交换**：非模态。
- 道集预览：可按 `trid` 过滤；横轴可选 `fldr/cdp/ep/offset/gx/sx`；点击联动。

---

## 9. 转换阶段（摘要）

| 类型 | 要点 |
|------|------|
| OBEM→SAC | 唯一参数为 obem `config.ini`（TSM 路径、台站、采样率等） |
| SAC→SEGY | SAC + UKOOA + sac2y INI；几何 **炮=sx/sy、OBS=gx/gy**；`scalco=scalel=-1`，`counit=1` |
| RAW→SAC | `fileName` + sps + TC；产出在执行 cwd |
| SEGY→SU | 道头几何字段 **原样拷贝** |
| 一键流水线 | sac2segy / sac2su / raw2segy / raw2su / obem2segy / obem2su |

详细输入输出见各转换页内嵌说明；示例 INI 在 `processors/raw2sac/*_config_example.ini`。
