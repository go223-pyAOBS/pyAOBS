# SEGY 道头：高程 / 水深 / 坐标（对照 segy.h）
# 实现：processors/raw2sac/segy_trace_header.py
# zplot 写入：visualization/zplotpy/su2z_hhb.py（字面映射，不交换角色）

# =============================================================================
# 1. 缩放因子（先读这两个，再解释下面的整型字段）
# =============================================================================
#
# scalel  → 作用于「前面 7 个」：gelev, selev, sdepth, gdel, sdel, swdep, gwdep
# scalco  → 作用于「后面 4 个」：sx, sy, gx, gy
#
# 规则（segy.h）：符号只表示乘/除，不是“负的倍数”
#   scale > 0 : 物理量 = 整型值 × scale          （正 → 乘）
#   scale < 0 : 物理量 = 整型值 ÷ |scale|        （负号 → 除；因子取绝对值）
#   scale = 0 或 ±1 : 不缩放
# 例：scalco=-100 → 米 = 整型坐标 / 100（绝不是 ×(-100)）
# 本工区约定物理单位：米（缩放后）
#
# 注意：offset（炮检距）不在这两组里，不受 scalco/scalel。

# =============================================================================
# 2. 高程 / 深度 / 水深（受 scalel）—— SEGY 字面含义
# =============================================================================
#
# 符号约定（海平面基准）：
#   高程 elev : 海平面以上为正，以下为负
#   深度 depth: 恒为正（向下为正）
#
# 字段          SEGY 字面（陆地/拖缆习惯）
# -----------   ------------------------------------------
# gelev         检波点(group) 相对海平面的高程
# selev         震源(source) 相对海平面的高程
# sdepth        震源深度（恒正；相对震源点/海面，依施工定义）
# gdel          检波点处的基准面(datum)高程
# sdel          震源处的基准面高程
# swdep         震源处水深（water depth at source）
# gwdep         检波点处水深（water depth at receiver group）
#
# 深度与高程的换算（同一点、海平面基准）：
#   depth ≈ -elev   （若 elev 为负高程，如 -2500 m → depth 2500 m）
#   若 sdepth>0 已填，可直接用 sdepth，不必再从 -selev 推

# =============================================================================
# 3. 水平坐标（受 scalco）—— SEGY 字面含义
# =============================================================================
#
# sx, sy        震源 X/Y
# gx, gy        检波点(group) X/Y
# 本工区：UTM，米（经 scalco 后）

# =============================================================================
# 4. 本工区 OBS：角色对调（字段名仍是 SEGY 名，装填对象对调）
# =============================================================================
#
# 原因：海上 OBS 常把「固定站」写进 source 槽、把「移动炮」写进 group 槽
#      （与 zplot 位置图「谁随道变化大谁是接收点」一致：sx 侧常是 OBS）
#
# 字段          SEGY 字面              本工区实际装填
# -----------   --------------------   ------------------------
# sx, sy        震源 XY                OBS 位置 UTM
# gx, gy        检波点 XY              炮点 UTM
# selev         震源高程               OBS 高程（海底，通常为负）
# gelev         检波点高程             炮点高程（近海面，通常≈0 或略负）
# sdepth        震源深度(正)           常填 OBS 沉放深度（正）；可与 -selev 等价
# swdep         震源处水深             常对应「source 槽」一侧 → 本工区≈ OBS 处水深
# gwdep         检波点处水深           常对应「group 槽」一侧 → 本工区≈ 炮点处水深
# gdel, sdel    基准面高程             按处理流程；RTM 网格若不用可忽略
#
# 记忆口诀（本工区）：
#   s* 槽 = Station / OBS（固定接收）
#   g* 槽 = Gun / 炮（移动震源）
# 这与 SEGY 英文 Source/Group 字面相反，以本工区装填为准。

# =============================================================================
# 5. RTM / su_to_shots.py
# =============================================================================
#
# --geom obs（默认）: 炮=(gx,gy,z←gelev)；OBS=(sx,sy,z←selev/sdepth) → km
# --geom segy:       按字面 Source=s*、Group=g*
#
# --geom offset（sx/sy/gx/gy 不可靠、仅信任 offset）:
#   --obs-x (km) = OBS 在速度模型测线上的位置
#   shot_x = obs_x + offset_sign * (offset_m / 1000)
#   默认 offset_sign=+1；剖面左右反了 → --offset-sign -1
#   z 仍用高程或 --zshot / --zobs-mode（与平面无关）
#   例: obs_x=0, offset=-342530 m, sign=+1 → shot_x=-342.53 km
#
# offset(m) 不受 scalco；|offset|>=1m 采信道头（可带符号）
#
# 坐标坏时推荐:
#   python su_to_shots.py --native --su xxx.su --component hydro \
#     --geom offset --obs-x 0 --offset-sign 1 \
#     --zshot 0.01 --zobs-mode const --zobs-const 1.901
